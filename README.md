# winOpt

> A lightweight Windows optimization and maintenance utility built with Python.


![windows](https://img.shields.io/badge/OS-Windows-blue) ![release](https://img.shields.io/badge/Pre--release-v0.3.3--alpha1-yellow) ![license](https://img.shields.io/badge/License-CC_BY--ND_4.0-red) ![version.py](https://img.shields.io/badge/python-3.14.0-blue)


winOpt is a Windows-focused command-line utility designed to provide
system maintenance, cleanup, optimization and software management
tools from a single interface.


## Screenshots

### Main Menu

![winOpt main menu](assets/screenshots/main-menu.png)


## Features

- Windows power plan management
- Disk maintenance tools
- Temporary file cleanup
- Software installation
- Driver management
- CLI interface
- Administrator privilege support


## Why winOpt?

winOpt provides commonly used Windows maintenance tools through
a single, simple command-line interface.

Instead of manually searching for different Windows utilities,
winOpt brings them together in one place.


## Installation

### Download

Download the latest Windows release from the Releases page.

Extract the archive and run `winOpt.exe`.


### Run from source

Clone the repository:

git clone https://github.com/aniciccstefan/winOpt.git

cd winOpt

python winOpt.py
